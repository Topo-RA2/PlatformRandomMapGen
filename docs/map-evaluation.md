# 随机地图评估 v2

`ra2-pvp-v2` 对一次原生生成结果做只读评估。它不选择 seed、不重生成地图、不改变下载资格，也不把地面不连通等玩法差异直接判为坏图。评估异常只影响报告本身，不能改变地图输出和任务成功。

## 总分

- 可玩性：基地空间可用性 60%，启用资源时初始经济可用性 40%。
- 公平性：基地空间均衡 30%，初始经济均衡 35%，出生布局均衡 20%，地面交通均衡 15%。未启用资源时移除初始经济权重后重新归一。
- 每个总分先计算加权平均，再按 `平均 70% + 最低子项 30%` 合成，避免单项严重短板被其他高分完全掩盖。
- 可信度按已覆盖领域加权。基地空间、初始经济、出生布局、地面交通置信度分别为 95、90、95、80；未启用资源时不计初始经济。

所有正式分数都是 `0..100` 整数。报告不使用浮点计算，同一地图、出生点和评估上下文必须生成字节一致的规范 JSON。

## 已覆盖领域

### 基地空间

- 可用性取所有玩家中的最低值。
- 7 步曼哈顿范围内可建造格：36 格开始得分，80 格达到满分，占 65%。
- 出生点所在四邻连通分量的可建造格：80 格开始得分；目标值为 `max(160, 全图可通行格 / (请求玩家数 * 2))`，占 35%。
- 均衡性比较各玩家本地可建造格与连通分量可建造格，权重 75%/25%。

### 初始经济

- 只在 `tiberium > 0` 时适用；否则 availability/parity 为 `null`，并产生 `economy.resource_free` observation。
- 每个出生点独立 BFS，统计 12、24、34 步内可达资源价值，并计算 34 步内按资源价值加权的平均距离。
- 可用性取所有玩家中的最低值：34 步资源价值 60 达到满分，占 70%；最近资源 12 步以内达到满分、35 步外为 0，占 30%。
- 均衡性比较 34 步资源价值与平均资源距离，权重 70%/30%。
- 资源按路径最近玩家归属；最近和次近距离差不超过 4 步时计为争夺资源，否则计为独占资源。

### 出生布局

- 比较每名玩家的最近出生点曼哈顿距离与路径 Voronoi 领地，权重 65%/35%。
- 该领域只提供均衡分，不提供可用性分，避免把快攻或长线布局预设为唯一正确玩法。

### 地面交通

- 一次全图四邻连通分量标记，加上每个出生点一次 BFS。
- 比较出生点所在分量的可通行面积与路径 Voronoi 领地，权重 60%/40%。
- `groundContactRatio` 表示可经地面连通的出生点对比例。它用于描述 topology，不直接扣可玩性。

均衡分同时考虑最小/最大比值和相对平均值偏差，权重 60%/40%。全部玩家同为 0 或全部不可达时，均衡性本身记为 100；对应的资源可用性仍会反映“全部缺失”，避免把共同短缺误写成不公平。

## 描述项

- `topology`：`single_land`、`islands`、`split_land`、`mixed`。
- `pace`：最近出生点距离除以地图短边，小于 45% 为 `fast`，45%..74% 为 `standard`，其余为 `long`。
- `resourceCentralization`：中央 50% 矩形内资源价值占全图资源价值的比例。
- `mapUtilization`：可通行格占全图格数的比例。
- `landFragmentation`：四邻可通行连通分量数量。
- `contestedTerritoryCells`：路径 Voronoi 中到多个玩家等距的格数。

## 策略适配度

原生生成器不评估策略适配度。现行 schema v2 的 `strategyFit` 使用 `score=null`、`confidence=0`，附加指标为 `null`；对应 coverage 为 `false`。

## 输出与验证

- CLI 在原生生成模式可写出 `--evaluation-report-out FILE`。
- preview/product 地图成功写出后才尝试写评估 JSON；报告写出失败只 warning 并保持退出码 0。
- MapTask 接受最大 32 KiB 的 schema v2 报告，并交叉核对 seed、尺寸和玩家数；缺失或非法时省略回调字段。
- Manager 再次规范化后写入可空的 `evaluation_version/evaluation_json`。旧记录或非法持久数据在读取时隐藏评估，不影响地图成功记录。
- `--mode verify-map-evaluation` 固化对称资源、关闭资源、资源失衡、独立岛屿 topology、不支持领域的 coverage 和 JSON 确定性。
